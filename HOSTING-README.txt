Creative IQ website | Static hosting

1. Back up the destination directory if it already hosts a site.
2. Upload and extract the ZIP in the document root for your domain
   or subdomain (for example, public_html in cPanel).
3. Keep index.html at that root and leave all folders in place.
   Serve index.html as the directory index so URLs such as /our-story/
   work when opened directly. Use HTTPS on the destination domain.
4. Open the homepage and test the menu, video and booking links.

The site is built and ready to serve. It uses root-relative URLs.
The reel and newsletter form use the original Creative IQ site.
Booking links open the existing booking services. Parent Login is a local
preview and does not send phone numbers, text messages or codes.
